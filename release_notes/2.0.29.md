# Награды и награждённые v2.0.29

Дата подготовки: 2026-10-22.

## Что изменилось

- Добавлен раздел «Обслуживание данных → Наполнение данных → Биографии»: статистика заполнения, выбор награды и выгрузка XLSX для заполнения биографий вручную или с помощью ИИ.
- Загрузка заполненного файла показывает строки «Готово к сохранению», «Требует проверки» и «Пропущено» с причинами. Скрытые сведения исходной выгрузки используются для строгой проверки личности и актуальности данных.
- Подтверждённое сохранение атомарно заполняет только пустые биографии существующих кавалеров; заполненные биографии, другие сведения, награды и фотографии сохраняются.
- Упрощены навигация и экран биографий: сначала статистика, затем последовательные шаги скачивания, заполнения, загрузки и проверки. «Оптимизация изображений» обозначена как «В разработке».

## Обновление

Owner candidate предназначен для ручной проверки обновления после подтверждения Windows handoff.
Откройте постоянную установку существующим пользовательским BAT, затем «О программе» → «Проверить обновления» → «Обновить» и дождитесь завершения установки.
После обновления приложение перезапустится автоматически, если эта настройка включена.
Повторно запускайте тот же BAT вручную только если приложение не открылось автоматически.
Данные, фотографии и документы при обновлении сохраняются.
