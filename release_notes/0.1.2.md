# 0.1.2

- Добавили сводную таблицу-шахматку по кавалерам и наградам.
- Добавили CSV-выгрузку шахматки для работы в Excel.
- Добавили кнопки “Открыть каталог” и “Архивировать” для материалов кавалера.
- Добавили выбор места сохранения для архива кавалера, PDF-буклета и CSV-файлов.
- Улучшили просмотр фотографий: теперь фото можно приближать, отдалять, сбрасывать масштаб и двигать мышкой.
- Добавили вставку фото из буфера обмена, если браузер поддерживает эту возможность.
- Добавили PDF-буклет по кавалеру с основными данными, биографией, ссылками, наградами и фотографиями.
- Включили рабочий режим редактирования: обычные изменения можно сохранять без создания резервной копии перед каждым действием.
- Улучшили каскадные справочники: страна → категория → подкатегория → наименование.
- Добавили обязательные поля, чтобы нельзя было создать пустого кавалера, награду или знак.
- Улучшили поиск: добавили нужные колонки, подсказки из базы и возврат к результатам поиска.
- Улучшили формы: ошибки стали понятнее, введённые данные сохраняются после ошибки.
- Улучшили главный экран “Награды”: сортировка кавалеров, быстрый поиск, внутренний скролл списка наград и одинаковые фото-карточки.
- Улучшили поток добавления кавалера: после создания сразу можно добавить фотографии и перейти к наградам.
- Улучшили поток добавления награды: после создания сразу можно добавить фотографии и документы.
- Улучшили карточку кавалера: длинные ФИО, ссылки, биография и комментарии теперь аккуратно переносятся.
