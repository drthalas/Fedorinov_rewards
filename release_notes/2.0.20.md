# Награды и награждённые v2.0.20

Дата релиза: 2026-09-09.

## Что изменилось

- Исправлено применение обновлённого интерфейса после установки: поиск по ФИО с пробелами работает без возврата старого поведения из кеша браузера.
- Повышена надёжность штатного запуска программы в Windows с сохранением проверок безопасности.
- В обоих буклетах скрыты пустые подробные разделы наград без фотографий и документов; полный верхний список наград и разделы с изображениями сохранены в HTML и PDF.

## Обновление

Откройте «О программе» → «Проверить обновления» → «Обновить» и дождитесь завершения установки.
Если включён автоматический перезапуск, программа откроется самостоятельно.
Запускайте start_windows.bat вручную только если программа не открылась автоматически.
Данные, фотографии и документы при обновлении сохраняются.
