# Награды и награждённые v2.0.32

Дата подготовки 2026-11-06.

## Что изменилось

- После завершённого импорта открывается компактный итог. Из него можно перейти к полному отчёту или скачать результаты по строкам.
- Быстрый поиск показывает «Ничего не найдено» при нуле совпадений и отдельно выводит общее число кавалеров.
- Галерея показывает доступные фотографии с подписями. Надпись «Нет фото» исчезает в слоте с предпросмотром или сохранённым снимком.
- Счётчик «Без наград» открывает постраничный список с переходом в карточку кавалера. Кнопка «Назад», цвет текста и пагинация оформлены в тёмной теме приложения.
- Импорт биографий различает доказательства ордена Славы I степени по точному номеру и по подтверждённому ФИО с контекстом. Контекстный путь допускает биографию. Замена ФИО требует подтверждения точного номера.
- Поддержка доказательств ГСС, проверка подписи исходной выгрузки и защита от записи поверх изменившихся карточек сохранены.

## Обновление

Owner candidate для ручной проверки обновления. Принятый source HEAD — `6db8e9894c7875671e09bc8a818359b8eb8b9ea8`.

После отдельного Windows handoff откройте постоянную установку существующим пользовательским BAT. В приложении выберите «О программе» → «Проверить обновления» → «Обновить». При включённом автоматическом перезапуске дождитесь открытия приложения.
