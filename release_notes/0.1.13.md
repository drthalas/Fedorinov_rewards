# Fedorinov Rewards v0.1.13

Релиз сфокусирован на удобстве работы с кавалерами и наградами: безопасное удаление, проверка дублей, единая навигация, просмотр наград, год рождения и упрощение главного экрана.

## Главное

- Главная вкладка переименована из "Награды" в "Кавалеры".
- Кнопка "Карточка" переименована в "Карточка кавалера".
- Дата рождения кавалера теперь отображается только годом.
- В формах кавалера вводится только год рождения.
- Главная страница "Кавалеры" стала страницей просмотра: действия редактирования наград убраны из правой панели.
- В карточке кавалера действия наград отображаются иконками.
- Экран просмотра награды показывает название награды, а не только ID.
- На внутренних страницах используется единая кнопка "Назад".
- Верхняя навигация унифицирована.

## Награды

- Добавлено безопасное удаление награды с подтверждением.
- Cancel/dismiss confirm больше не удаляет запись.
- Добавлена проверка дублей наград по всей базе.
- Дубль определяется по связке "наименование + номер".
- Пустой номер разрешён и не проверяется.
- Добавлена интерактивная подсветка номера награды.
- Исправлен скролл "Перечень наград".

## Навигация

- Верхнее меню теперь единое: "Кавалеры", "Поиск", "Знаки", "Свод.таблица", "Справочник", "О программе".
- Убраны пользовательские пункты "Главная", "Диагностика", "Health".
- На внутренних страницах оставлена единая локальная кнопка "Назад".
- Safe return_to сохранён, внешние URL блокируются.
