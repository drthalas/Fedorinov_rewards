# Награды и награждённые v2.0.35

Дата подготовки 2026-11-19.

## Что изменилось

- В списке «Без наград» можно выбрать конкретную награду и увидеть всех кавалеров, у которых её нет, включая обладателей других наград.
- Сброс возвращает исходный список без единой награды. При возврате из карточки сохраняются выбранный фильтр и страница списка.

## Owner candidate

Windows-кандидат ALE-541 для ручного обновления и проверки.
Принятый feature HEAD — `1c74ff3c196693ea17dc3bf7fc5edc76960ab619`.

затем откройте «О программе» → «Проверить обновления» → «Обновить».
После обновления дождитесь автоматического перезапуска приложения.
