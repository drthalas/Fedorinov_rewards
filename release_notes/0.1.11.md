# v0.1.11

## Главное

- Во вкладке "Награды" при переключении кавалеров теперь показывается "Загрузка карточки кавалера…".
- Быстрый набор по ФИО стал устойчивее к медленному вводу.
- Навигация Arrow/Page/Home/End по списку кавалеров сохранена и доработана.
- Нижняя дублирующая кнопка "Показать все фото" убрана, верхняя кнопка сохранена.
- В карточке кавалера добавлена отдельная кнопка "Назад".
- Убран дублирующий блок информации рядом с "Краткая биография".
- Главное фото, краткая биография, ссылки и нижняя зона фотографий стали крупнее и удобнее.
- Фотографии в карточке отображаются в два ряда.
- Во вкладке "Поиск" длинные названия фильтров теперь читаются корректно.
- В поиске добавлена пагинация результатов по 50 строк.
- Изменение высоты одной строки поиска теперь применяется ко всем строкам таблицы.
- CSV поиска по-прежнему выгружает полный результат, а не только текущую страницу.
