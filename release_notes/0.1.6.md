# v0.1.6

## Главное

- Исправлен режим “мини-фото” во вкладке “Поиск”.
- Фотографии в таблице теперь показываются компактными превью, а не раздувают строки.
- Для отсутствующих фото отображается placeholder того же размера.
- Полное фото по-прежнему открывается по клику в просмотрщике.
- Lightbox/zoom, resize колонок/строк и CSV остались рабочими.

## Проверено

- Мини-фото отображаются компактно.
- Строки таблицы остаются нормальной высоты.
- Клик по мини-фото открывает просмотрщик.
- CSV остаётся текстовым без картинок.
- Внутренние пути к файлам не выводятся.
- Сергей визуально подтвердил результат.

## Примечание

- Windows native Save As check по ALE-182 остаётся отложенным владельцем и не входит в этот patch release.
