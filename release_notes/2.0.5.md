# Награды и награждённые v2.0.5

Дата релиза: 2026-07-22.

## Что изменилось

- После создания кавалера его карточка остаётся выбранной, поэтому результат сохранения сразу виден.
- Обязательные поля форм стали понятнее, а год рождения принимается только в корректном четырёхзначном формате.
- Проверка номера награды больше не зависит от порядка ввода и не мешает редактированию, если номер не изменялся.
- Для полей форм отключены случайные подсказки браузера из ранее введённых значений.
- Сохранены принятые улучшения фотографий, каталога и скорости открытия карточек на больших базах.
- Обновление надёжно останавливает старый процесс приложения и запускает единственный новый backend актуальной версии.
- Установка и обновление продолжают использовать закреплённые зависимости.

## Как обновиться

Откройте «О программе», нажмите «Проверить обновления», затем «Обновить». Дополнительных действий не требуется.
