# Fedorinov Rewards v2.0.3

Версия 2.0.3 восстанавливает согласованный фон раздела «Кавалеры» в Windows-приложении и заметно ускоряет открытие карточек на больших базах.

## Кавалеры

- Согласованная фотография снова отображается на пустом экране «Кавалеры» в установленном приложении.
- Оптимизированная доставка изображения совместима с updater предыдущих публичных версий.
- Карточки кавалеров, включая записи с большим количеством наград, открываются значительно быстрее.

## Надёжность

- Подготовка сведений для удаления выполняется только при открытии подтверждения, а не при обычном просмотре карточки.
- Загрузка карточки больше не может оставлять бесконечный индикатор: при сетевой ошибке или превышении времени ожидания показывается понятное сообщение и действие можно повторить.
- Сохранены точные сведения в подтверждении удаления, защита общих материалов, безопасное восстановление незавершённых операций и существующие пользовательские данные.

## Обновление

- Обновление сохраняет пользовательскую базу, фотографии и документы.
- Перед установкой штатно создаётся резервная копия приложения.
