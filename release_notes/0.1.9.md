# v0.1.9

## Главное

- Восстановлена обычная листалка всех фото кавалера.
- Все безопасные фото из папки кавалера теперь входят в обычный просмотр фотографий карточки.
- Дополнительные фото можно листать сразу из карточки, без обязательного нажатия “Показать все фото”.
- Кнопка “Показать все фото” остаётся отдельным обзором, но больше не является единственным способом увидеть полный набор фото.
- Просмотр фотографий убирает дубли.
- Служебные пути к файлам не показываются пользователю.
- Небезопасные файлы не добавляются в просмотр фотографий.
- Карточка кавалера заметно уплотнена.
- Фото больше не раздувают карточку.
- Горизонтального переполнения карточки не обнаружено.
