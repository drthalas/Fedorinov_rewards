# Награды и награждённые v2.0.13

Дата релиза: 2026-08-13.

## Что изменилось

- Фильтры кавалеров надёжно работают на больших базах и сохраняются при переходах по алфавитным и цифровым группам.
- Создание кавалера стало последовательным: фотографии и несколько наград можно добавить до финального сохранения.
- Вкладка «Поиск» сохраняет своё состояние в текущем сеансе, а «Сводная таблица» быстрее показывает первые результаты постранично.
- В списках наград отображаются изображения из справочника, когда они доступны.
- Добавление фотографий сначала проверяет буфер обмена, а затем при необходимости открывает выбор файла.
- Поля награды последовательно уточняются по государству, категории и подкатегории; ссылка из справочника подставляется автоматически.
- Переходы между экранами остаются плавными, без белых промежуточных кадров.

## Обновление

Обновление устанавливается штатной кнопкой в приложении. База, фотографии и документы сохраняются автоматически.
