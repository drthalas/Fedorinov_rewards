# v0.1.10

## Главное

- В правом блоке "Фото" на вкладке "Награды" клик по фото теперь открывает просмотр полного набора фото кавалера.
- Для Вукаловича Семёна Петровича в блоке видно основные фото, но просмотр листает весь набор из 16 фото.
- "Показать все фото" больше не является единственным способом увидеть полный набор фото.
- Со страницы "Показать все фото" кнопка "← Вернуться" возвращает обратно во вкладку "Награды" к выбранному кавалеру.
- В правый блок "Фото" добавлен компактный подблок "Документы".
- В подблок добавлены: учётная карточка, сторона 1; учётная карточка, сторона 2; наградная книжка, сторона 1; наградная книжка, сторона 2.
- Если документа нет, показывается "Нет фото".
- Исправлен layout карточки в Windows Edge: длинные ссылки больше не ломают карточку.
- Добавлен cache-busting для CSS/JS, чтобы браузер не оставлял старое поведение после обновления.
