# v0.1.7

## Главное

- Исправлен быстрый поиск ФИО: основной сценарий теперь явное поле “Быстрый поиск по ФИО”.
- Enter открывает первое совпадение в списке кавалеров.
- Список кавалеров больше не перехватывает ввод и не автофокусится после загрузки.
- Мини-фото в поиске компактные и не отображаются в реальном размере.
- Режим мини-фото явно доступен на вкладке “Поиск”.
- Улучшены resize-ручки колонок и строк в поиске.
- Resize работает в режиме `0/1` и в режиме мини-фото.
- Save As честно объясняет ограничение браузера: веб-страница не может автоматически открыть локальную папку.
- Fallback download и “Открыть копию файла” сохранены.
- CSV и PDF остались рабочими.
