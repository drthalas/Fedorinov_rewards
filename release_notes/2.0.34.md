# Награды и награждённые v2.0.34

Дата подготовки 2026-11-19.

## Что изменилось

- При сохранении карточки без наград появляется отдельное предупреждение с выбором «Добавить награду» или «Сохранить без награды». Введённые данные сохраняются при возврате к форме.
- Материалы одного кавалера в общем PDF обычных буклетов размещаются компактнее. Каждый следующий кавалер начинается с новой страницы.
- В «Шахматке по кавалерам» добавлены колонки «Биография» с признаком 1/0 и «Комментарий» с переносом длинного текста.
