# Награды и награждённые v2.0.19

Дата релиза: 2026-09-08.

## Что изменилось

- Упрощены элементы формы награды и выбор фотографий для PDF.
- В составе PDF сводной таблицы можно выбрать книжную или альбомную ориентацию; по умолчанию используется книжная, фотографии аккуратно вписываются в обе версии.
- Буклет кавалера оформлен как историческое досье с биографией, фотографиями, документами и наградами на фактурной архивной бумаге.
- Добавлен отдельный «Буклет 2» с художественной композицией фотографий и документов без подписей; обычный буклет сохраняет центрированные подписи.
- Поиск по ФИО корректно сохраняет пробелы, а наименования наград в фильтрах расположены по алфавиту.

## Обновление

Откройте «О программе» → «Проверить обновления» → «Обновить» и дождитесь завершения установки.
Если включён автоматический перезапуск, программа откроется самостоятельно.
Запускайте start_windows.bat вручную только если программа не открылась автоматически.
Данные, фотографии и документы при обновлении сохраняются.
