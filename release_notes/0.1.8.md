# v0.1.8

## Главное

- Уплотнена карточка кавалера, открываемая после double click.
- Карточка лучше помещается на один экран.
- Slideshow теперь включает дополнительные безопасные фото из каталога кавалера.
- Дубли фото в slideshow убираются.
- Absolute paths в UI не раскрываются.
- CSV больше не выводит boolean как true/false — теперь используется 1/0.
- CSV остаётся Excel-friendly: UTF-8 BOM и разделитель “;”.
- Save As честно объясняет ограничение браузера: web-страница не получает путь выбранной пользователем папки.
- Fallback download / “Открыть копию файла” сохранён.
- В “Сводной таблице” добавлен resize колонок и строк.
- В “Поиске” мини-фото масштабируются при изменении ширины колонок и высоты строк.
- Lightbox после resize работает.
