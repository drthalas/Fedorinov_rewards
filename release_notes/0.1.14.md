# Fedorinov Rewards v0.1.14

Релиз сфокусирован на удобстве работы с кавалерами, наградами и справочником: безопасное удаление, проверка дублей, единая навигация, упрощение карточек, год рождения, ручной рейтинг и изображения в справочнике.

## Главное

- Главная вкладка переименована из "Награды" в "Кавалеры".
- Кнопка "Карточка" переименована в "Карточка кавалера".
- Дата рождения кавалера теперь отображается только годом.
- В формах кавалера используется поле "Год рождения".
- ID кавалера убран из пользовательского отображения на главной странице.
- Заголовок редактирования награжденного больше не содержит технический `#id`.
- Главная страница "Кавалеры" стала страницей просмотра: действия редактирования наград убраны из правой панели.
- В карточке кавалера действия наград отображаются иконками.

## Награды

- Добавлено безопасное удаление награды с подтверждением.
- Cancel/dismiss confirm больше не удаляет запись.
- Добавлена проверка дублей наград по всей базе.
- Дубль определяется по связке "наименование + номер".
- Пустой номер разрешён и не проверяется.
- Добавлена интерактивная подсветка номера награды.
- Исправлен скролл "Перечень наград".
- Экран просмотра награды показывает название награды, а не только ID.

## Навигация

- Верхнее меню теперь единое: "Кавалеры", "Поиск", "Знаки", "Свод.таблица", "Справочник", "О программе".
- Убраны пользовательские пункты "Главная", "Диагностика", "Health".
- На внутренних страницах оставлена единая локальная кнопка "Назад".
- Исправлен цикл "Назад" после перехода из карточки кавалера в добавление награды.
- Safe `return_to` сохранён, внешние URL блокируются.

## Справочник

- В справочнике наград и знаков добавлено ручное поле "Рейтинг".
- Добавлена ручная загрузка, замена и удаление изображения элемента справочника.
- Рейтинг и миниатюра отображаются в дереве.
- Заголовки редактирования стали понятнее: "Орден: ...", "Медаль: ...", "Знак: ...".
- Дерево сохраняет раскрытое состояние после переходов в edit/add и обратно.
- После выбора файла preview изображения появляется сразу.
- Исправлено сворачивание дерева после сохранения рейтинга/изображения.
- Постоянная жёлтая подсветка focus-элемента убрана.
- Автоматический импорт рейтинга не выполнялся.
- Картинки из интернета не скачивались.
