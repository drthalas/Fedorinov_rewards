# Fedorinov Rewards v2.0.1 — Updater Compatibility Hotfix

Версия 2.0.1 исправляет установку полного визуального обновления на компьютерах с предыдущими Windows-версиями приложения.

## Обновление

- Исправлена ошибка `forbidden file type` при проверке системных элементов нового интерфейса.
- Пользователям, столкнувшимся с ошибкой v2.0.0, достаточно снова нажать «Обновить».
- Новый совместимый пакет устанавливает полный дизайн v2 без ручного копирования файлов и очистки временных данных.
- Улучшена совместимость и безопасность проверки будущих обновлений.

## Интерфейс

- Полностью сохранён архивно-военный визуальный редизайн v2.
- Системные изображения интерфейса доступны локально и не требуют подключения к интернету после установки.
- Кавалеры, Справочник, Поиск, Знаки, Сводная таблица и О программе сохраняют принятый внешний вид.

## Данные

- Пользовательская база, фотографии и документы не изменяются процедурой обновления.
- Перед установкой штатно создаётся резервная копия файлов приложения.
- Совместимость проверена на копии предыдущей версии с временными данными и media-каталогом.
