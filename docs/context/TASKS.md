# Задачи и roadmap

Этот файл фиксирует актуальное состояние проекта после релиза v0.1.11.
Исторические детали по этапам смотри в `CHANGELOG.md` и Git history.

## Выпущено

### v0.1.0

Статус: выпущено.

- Первая Windows portable preview-сборка.
- Основной legacy-интерфейс.
- Базовая проверка обновлений через публичный GitHub Release.
- Исправление отображения фото на Windows.

### v0.1.1

Статус: выпущено.

- Видимый статус процесса обновления.
- Фильтры и итоги на главном экране "Награды".
- Улучшенный поиск.
- Переходы в справочники из форм.
- Возврат из карточки кавалера обратно на главный экран.
- Telegram-уведомления о релизах.

### v0.1.2

Статус: выпущено.

- Рабочий режим записи.
- Сводная таблица-шахматка по кавалерам и наградам.
- CSV-выгрузка шахматки.
- Открытие каталога кавалера.
- Архивирование материалов кавалера.
- Системный выбор места сохранения для архива, PDF-буклета и CSV.
- Zoom / pan / reset в просмотре фото.
- Вставка фото из буфера обмена, если браузер поддерживает Clipboard API.
- PDF-буклет кавалера.
- Каскадные справочники: страна -> категория -> подкатегория -> наименование.
- Обязательные поля для кавалера, награды и знака.
- Улучшенный поиск: пользовательские колонки, подсказки из базы, возврат к результатам.
- Финальная полировка форм и русские сообщения об ошибках.
- Сохранение файлов через браузерный Save As для архива, PDF-буклета и CSV; fallback остаётся для браузеров без поддержки.
- Главный экран "Награды": алфавитная сортировка кавалеров, быстрый поиск слева, внутренний скролл наград, единые фото-фреймы.
- Улучшенный поток добавления кавалера: после создания сразу доступны фото и переход к наградам.
- Улучшенный поток добавления награды: после создания сразу доступны фото и документы награды.
- Карточка кавалера и legacy-панель аккуратно переносят длинные ФИО, ссылки, биографию и комментарии.

### v0.1.3

Статус: выпущено.

- Исправлены фото-фреймы на главном экране и карточке кавалера: реальные фото и блоки "Нет фото" находятся в одинаковых серых рамках.
- Фото внутри рамки центрируется, сохраняет пропорции и не растягивается.
- Добавлен PDF-экспорт сводной таблицы.
- Добавлен PDF-экспорт режима "Шахматка по кавалерам".
- PDF учитывает выбранные фильтры.
- Для слишком широкой таблицы показывается понятное сообщение с предложением использовать фильтры или CSV.

### v0.1.4

Статус: выпущено.

- Главный экран "Награды": выбранный кавалер остаётся видимым в левом списке.
- Дополнительное подтверждение удаления кавалера.
- Строка итогов закреплена внизу рабочей области.
- Форма редактирования кавалера стала компактнее: фотографии доступны в первом экране.
- Краткая биография сохраняется и отображается.
- Сводная таблица: каскадные фильтры и сортировка шахматки по столбцам.
- CSV: после сохранения показывается понятная подсказка, где открыть файл.
- Поиск: поиск по номеру награды и сортировка результатов по столбцам.
- Поиск и CSV: новые признаки фото и документов по наградам.
- Фото, вставленные из буфера обмена, сохраняются в JPEG.

### v0.1.5

Статус: выпущено.

- CSV-файлы открываются в Excel по колонкам.
- Карточка кавалера стала читабельнее: ФИО, звание, дата и ссылки не схлопываются в узкие колонки.
- На вкладке "Награды" добавлена клавиатурная навигация по списку кавалеров.
- Добавлен быстрый поиск по первым буквам ФИО прямо в списке кавалеров.
- Справочник "Звания / специальности" открывается по алфавиту.
- Во вкладке "О программе" отображается дата версии.
- Название программы можно редактировать и сохранять.
- Краткая биография сохраняется и отображается после перезагрузки.
- Форма редактирования кавалера стала компактнее.
- Во вкладке "Поиск" добавлен режим мини-фото вместо признаков `0/1`.
- Мини-фото открываются в существующем просмотрщике с zoom/lightbox.
- Таблицу поиска можно настраивать по ширине колонок и высоте строк.
- При поиске по наименованию награды добавлены колонки фото наградной книжки, сторона 1/2.
- Save As для PDF/CSV получил понятный fallback download и честные сообщения про ограничения браузера.
- Windows native Save As через отдельную Windows VM пока отложен владельцем и не блокирует релиз.

### v0.1.6

Статус: выпущено.

- Исправлен режим "мини-фото" во вкладке "Поиск".
- Фотографии в таблице показываются компактными превью и не раздувают строки.
- Placeholder для отсутствующих фото имеет такой же размер, как ячейка с фото.
- Полное фото открывается по клику в существующем просмотрщике.
- Lightbox/zoom, resize колонок и строк, сортировка и CSV не сломаны.
- Windows native Save As по ALE-182 остаётся отложенной проверкой владельца.

### v0.1.7

Статус: выпущено.

- Объединяет стабильную базу v0.1.5, исправление мини-фото из v0.1.6 и финальные исправления ALE-192.
- Быстрый поиск ФИО работает через явное поле "Быстрый поиск по ФИО".
- Enter открывает первое совпадение в списке кавалеров.
- Список кавалеров не автофокусится после загрузки и не перехватывает ввод как основной сценарий.
- Мини-фото в поиске компактные: frame 44x44 px, изображение до 40x40 px, placeholder такого же размера.
- Resize-ручки колонок и строк в поиске стали заметнее.
- Save As честно объясняет ограничение браузера на автоматическое открытие локальной папки.
- Fallback download и "Открыть копию файла" сохранены.
- Проверки: 282 tests PASS, data/media baseline PASS, smoke PASS.

### v0.1.8

Статус: выпущено.

- Включает исправления ALE-195 после проверки владельца v0.1.7.
- Уплотнена карточка кавалера `/persons/{id}`, открываемая double click из вкладки "Награды".
- Slideshow карточки кавалера дополняется безопасными фото из каталога кавалера.
- Дубли фото в slideshow убираются, absolute paths в UI не раскрываются.
- CSV boolean `true/false` заменены на `1/0`, Excel-friendly формат сохранён.
- Save As честно объясняет ограничение браузера: web-страница не получает путь выбранной папки и не может открыть её автоматически.
- В "Сводной таблице" добавлен resize колонок и строк.
- В "Поиске" мини-фото масштабируются при изменении ширины колонок и высоты строк.
- Проверки: 283 tests PASS, data/media baseline PASS, smoke PASS.
- SHA256 release package фиксируется в `latest.json`, GitHub Release и финальном отчёте после сборки.

### v0.1.9

Статус: выпущено.

- Включает исправления ALE-197 после проверки владельца v0.1.8.
- Восстановлена обычная листалка всех фото кавалера.
- Все безопасные фото из папки кавалера входят в обычный slideshow карточки.
- Дополнительные фото можно листать сразу из карточки, без обязательного нажатия "Показать все фото".
- Lightbox убирает дубли фото, absolute paths в UI не раскрываются.
- Unsafe files не добавляются.
- Карточка кавалера заметно уплотнена.
- Добавлены viewport-limit и внутренние scroll-блоки.
- Фото не раздувают карточку, horizontal overflow не обнаружен.
- Проверки: 284 tests PASS, data/media baseline PASS, smoke PASS.
- SHA256 release package фиксируется в `latest.json`, GitHub Release и финальном отчёте после сборки.

### v0.1.10

Статус: выпущено.

- Включает стабильную базу v0.1.9 и hotfix-исправления ALE-218, ALE-219, ALE-220.
- Windows Edge layout карточки кавалера исправлен: длинные ссылки показываются compact labels и не ломают карточку.
- CSS/JS получают cache-busting, чтобы после обновления не оставалось старое поведение.
- На вкладке "Награды" в правом блоке "Фото" клик по видимому фото открывает full lightbox кавалера.
- Для `/legacy?tab=rewards&person_id=77` full lightbox содержит 16 фото.
- `/persons/77/photos` возвращает обратно в `/legacy?tab=rewards&person_id=77`.
- В правый блок "Фото" добавлен подблок "Документы": учётная карточка 1/2 и наградная книжка 1/2.
- Для отсутствующих документов показывается "Нет фото".
- Проверки: 292 tests PASS, data/media baseline PASS.
- SHA256 release package фиксируется в `latest.json`, GitHub Release и финальном отчёте после сборки.

### v0.1.11

Статус: выпущено.

- Включает стабильную базу v0.1.10 и итерации ALE-222, ALE-223, ALE-224.
- Вкладка "Награды": loading state при переключении кавалеров, устойчивый typeahead по ФИО, доработанная навигация Arrow/Page/Home/End.
- Вкладка "Награды": нижняя дублирующая кнопка "Показать все фото" убрана, верхняя кнопка и return flow сохранены.
- Карточка кавалера: добавлена кнопка "Назад", удалён дублирующий инфо-блок, увеличены главное фото, биография, ссылки и зона фотографий.
- Карточка кавалера: фотографии отображаются в два ряда, full lightbox сохранён.
- Поиск: длинные названия фильтров читаются корректно.
- Поиск: добавлена пагинация по 50 строк, диапазон "Показаны X–Y из Z", кнопки "Первая", "Предыдущая", "Следующая", "Последняя".
- Поиск: высота строк меняется синхронно для всей таблицы и сохраняется при переходе страниц.
- CSV поиска выгружает полный результат, а не только текущую страницу.
- Проверки: owner/manual PASS по ALE-222, ALE-223, ALE-224; 299 tests PASS, data/media baseline PASS.
- SHA256 release package: `80e23581d58457d77e6c3a3021164ba4ec033acff6556a411fdf0730742b3fdb`.

## Backlog

- Подключение полной рабочей базы владельца.
- Диагностика данных: битые фото, дубли, пустые номера, некорректные даты, неиспользуемые справочники, файлы без привязки.
- Полировка интерфейса под старую Windows-программу.
- Автоматический перезапуск после обновления.
- Расширенные отчёты и аналитика.
- Windows-установщик.
- Очистка отвязанных QA-файлов.
- Убрать пользовательские read-only/write-mode режимы из интерфейса и оставить обычную рабочую программу.

## Правила работы с roadmap

- Linear хранит задачи и статусы.
- `docs/context` хранит постоянную память проекта.
- Git history остаётся фактом изменений.
- Hermes QA подтверждает качество перед релизом.
- Новые задачи после проверки владельцем оформлять отдельными русскими Linear issues.
