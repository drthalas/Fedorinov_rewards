# Задачи и roadmap

Этот файл фиксирует актуальное состояние проекта после подготовки релиза v0.1.5.
Исторические детали по этапам смотри в `CHANGELOG.md` и Git history.

## Выпущено

### v0.1.0

Статус: выпущено.

- Первая Windows portable preview-сборка.
- Основной legacy-интерфейс.
- Базовая проверка обновлений через публичный GitHub Release.
- Исправление отображения фото на Windows.

### v0.1.1

Статус: выпущено.

- Видимый статус процесса обновления.
- Фильтры и итоги на главном экране "Награды".
- Улучшенный поиск.
- Переходы в справочники из форм.
- Возврат из карточки кавалера обратно на главный экран.
- Telegram-уведомления о релизах.

### v0.1.2

Статус: выпущено.

- Рабочий режим записи.
- Сводная таблица-шахматка по кавалерам и наградам.
- CSV-выгрузка шахматки.
- Открытие каталога кавалера.
- Архивирование материалов кавалера.
- Системный выбор места сохранения для архива, PDF-буклета и CSV.
- Zoom / pan / reset в просмотре фото.
- Вставка фото из буфера обмена, если браузер поддерживает Clipboard API.
- PDF-буклет кавалера.
- Каскадные справочники: страна -> категория -> подкатегория -> наименование.
- Обязательные поля для кавалера, награды и знака.
- Улучшенный поиск: пользовательские колонки, подсказки из базы, возврат к результатам.
- Финальная полировка форм и русские сообщения об ошибках.
- Сохранение файлов через браузерный Save As для архива, PDF-буклета и CSV; fallback остаётся для браузеров без поддержки.
- Главный экран "Награды": алфавитная сортировка кавалеров, быстрый поиск слева, внутренний скролл наград, единые фото-фреймы.
- Улучшенный поток добавления кавалера: после создания сразу доступны фото и переход к наградам.
- Улучшенный поток добавления награды: после создания сразу доступны фото и документы награды.
- Карточка кавалера и legacy-панель аккуратно переносят длинные ФИО, ссылки, биографию и комментарии.

### v0.1.3

Статус: выпущено.

- Исправлены фото-фреймы на главном экране и карточке кавалера: реальные фото и блоки "Нет фото" находятся в одинаковых серых рамках.
- Фото внутри рамки центрируется, сохраняет пропорции и не растягивается.
- Добавлен PDF-экспорт сводной таблицы.
- Добавлен PDF-экспорт режима "Шахматка по кавалерам".
- PDF учитывает выбранные фильтры.
- Для слишком широкой таблицы показывается понятное сообщение с предложением использовать фильтры или CSV.

### v0.1.4

Статус: выпущено.

- Главный экран "Награды": выбранный кавалер остаётся видимым в левом списке.
- Дополнительное подтверждение удаления кавалера.
- Строка итогов закреплена внизу рабочей области.
- Форма редактирования кавалера стала компактнее: фотографии доступны в первом экране.
- Краткая биография сохраняется и отображается.
- Сводная таблица: каскадные фильтры и сортировка шахматки по столбцам.
- CSV: после сохранения показывается понятная подсказка, где открыть файл.
- Поиск: поиск по номеру награды и сортировка результатов по столбцам.
- Поиск и CSV: новые признаки фото и документов по наградам.
- Фото, вставленные из буфера обмена, сохраняются в JPEG.

### v0.1.5

Статус: готовится к выпуску.

- CSV-файлы открываются в Excel по колонкам.
- Карточка кавалера стала читабельнее: ФИО, звание, дата и ссылки не схлопываются в узкие колонки.
- На вкладке "Награды" добавлена клавиатурная навигация по списку кавалеров.
- Добавлен быстрый поиск по первым буквам ФИО прямо в списке кавалеров.
- Справочник "Звания / специальности" открывается по алфавиту.
- Во вкладке "О программе" отображается дата версии.
- Название программы можно редактировать и сохранять.
- Краткая биография сохраняется и отображается после перезагрузки.
- Форма редактирования кавалера стала компактнее.
- Во вкладке "Поиск" добавлен режим мини-фото вместо признаков `0/1`.
- Мини-фото открываются в существующем просмотрщике с zoom/lightbox.
- Таблицу поиска можно настраивать по ширине колонок и высоте строк.
- При поиске по наименованию награды добавлены колонки фото наградной книжки, сторона 1/2.
- Save As для PDF/CSV получил понятный fallback download и честные сообщения про ограничения браузера.
- Windows native Save As через отдельную Windows VM пока отложен владельцем и не блокирует релиз.

## Ближайшее после v0.1.5

- Проверка владельцем после v0.1.5.
- Подтвердить обновление через кнопку "Обновить" на стороне владельца.
- Проверить CSV в Excel.
- Проверить карточку кавалера, биографию, клавиатуру и быстрый поиск ФИО.
- Проверить фото-режим поиска и изменение размеров таблицы.
- Позже вручную проверить Windows native Save As.
- Собрать новую обратную связь владельца.
- Завести отдельные Linear issues на найденные замечания.

## Backlog

- Backup / Restore в интерфейсе.
- Подключение полной рабочей базы владельца.
- Диагностика данных: битые фото, дубли, пустые номера, некорректные даты, неиспользуемые справочники, файлы без привязки.
- Полировка интерфейса под старую Windows-программу.
- Автоматический перезапуск после обновления.
- Расширенные отчёты и аналитика.
- Windows-установщик.
- Очистка отвязанных QA-файлов.
- Убрать пользовательские read-only/write-mode режимы из интерфейса и оставить обычную рабочую программу.

## Правила работы с roadmap

- Linear хранит задачи и статусы.
- `docs/context` хранит постоянную память проекта.
- Git history остаётся фактом изменений.
- Hermes QA подтверждает качество перед релизом.
- Новые задачи после проверки владельцем оформлять отдельными русскими Linear issues.
