# Контекст проекта

## Название

"Кавалеры и награды".

Публичное название приложения в интерфейсе:

```text
Награды и награждённые
```

## Цель

Сделать web-версию и рабочую замену старой Windows-программы для ведения коллекции кавалеров, наград, знаков, фотографий и документов.

Основная задача — сохранить привычную логику старой программы, но сделать её удобнее, безопаснее и поддерживаемой.

- Александр — владелец разработки и процесса.

## Что хранится в данных

В локальной базе и папках данных хранятся:

- кавалеры / награждённые;
- награды;
- знаки;
- справочники званий и дерева наград;
- фотографии кавалеров;
- фотографии наград и знаков;
- документы: наградные книжки, учётные карточки, наградные листы;
- ссылки, биографии, комментарии, номера и цены.

## Структура локальных данных

Ожидаемая папка данных содержит:

```text
database/MyDatabase.sqlite
Source/
SourceMark/
default/
```

`database` содержит SQLite-базу.

`Source` содержит материалы кавалеров и наград.

`SourceMark` содержит материалы знаков.

`default` содержит fallback-изображения и вспомогательные файлы.

## Локальный режим работы

Разработка и QA используют безопасный dev data root:

```text
/Users/hermes/LocalData/FedorinovRewards/Rewards
```

Рабочая Windows-сборка использует локальный `REWARDS_DATA_DIR` владельца. Приложение работает локально и не отправляет базу или фотографии наружу.

## Обновления

Обновления доставляются через public GitHub Releases:

```text
https://github.com/drthalas/Fedorinov_rewards/releases/latest/download/latest.json
```

Владелец проверяет обновление из вкладки "О программе" и устанавливает его кнопкой "Обновить". GitHub token на компьютере владельца не нужен.

## Telegram
