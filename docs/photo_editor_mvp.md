# ALE-497 — локальная аналитика и контракт MVP

Дата: 18.10.2026. Ветка: feature/ux-photo-editing.

Редактор в существующих photo controls награды и документов. Последовательность:
загрузить штатным способом → «Редактировать» → выделить свободный прямоугольник
мышью/касанием, изменить яркость → предпросмотр → Сброс / Отмена / Сохранить.
Повторное выделение заменяет область; Сброс возвращает весь исходный кадр и яркость.

Локальный Canvas рисует preview; Pillow (существующая зависимость) обрабатывает
исходные пиксели на сервере. CDN/API не нужны. EXIF orientation нормализуется.
Результат — PNG без повторной потери JPEG-качества, с сохранением прозрачности;
не более 40 млн исходных пикселей и 25 MB результата. Яркость: 25–200%.
Поворот, контраст, resize оценены как возможные следующие функции, отложены.

Файл получает уникальное имя. Запись файла завершается до SQLite commit;
при ошибке новый файл удаляется, старая ссылка остаётся. Перед записью в
транзакции проверяется исходная ссылка: параллельная замена даёт конфликт.
Старый файл удаляется только существующим reference-aware cleanup, если на него
больше никто не ссылается. Отдельный архив оригиналов MVP не создаёт.
Отмена/Сброс работают в памяти браузера. Ошибка оставляет редактор открытым.
Асинхронный Save обновляет только фото и hidden path, сохраняя прочие поля формы.
Новая ссылка исключает устаревший кэш в форме/карточке/поиске/lightbox.

Draft хранит фото отдельно от SQLite. Для него целесообразно переиспользовать
preview и штатный staged upload; если optimistic-save потребует отдельного
контракта, оставить редактирование доступным после создания награды и указать
ограничение. Существующие draft upload/cancel/commit остаются обязательной
регрессией, photo controls кавалера вне MVP.

Acceptance: реальный browser flow crop/brightness/reset/cancel/save, сохранность
несохранённых полей, новые пиксели после reload в форме/карточке/поиске/lightbox;
focused temp tests shared references, conflict, filesystem/SQLite failure,
валидации и write guard. Никаких real DB/media, full suite или Windows gate.
