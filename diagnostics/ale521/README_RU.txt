ALE-521 — безопасная диагностика импорта, комплект v2

1. Скачайте ZIP и нажмите «Извлечь всё». Распакуйте в ОТДЕЛЬНУЮ папку,
   не поверх программы. Не запускайте BAT непосредственно из ZIP.
2. Дважды нажмите START_DIAGNOSTIC.bat.
3. Выберите папку той программы, которой пользуетесь для импорта
   (внутри находятся start_windows.bat, backend и .venv).
4. Выберите скачанный финальный XLSX из Drive — тот, который отклоняется.
5. Выберите место для нового JSON, например Рабочий стол. Дождитесь «Готово».
6. Передайте Александру ТОЛЬКО этот JSON.

Python устанавливать, команды редактировать и приложение обновлять НЕ нужно.
Комплект использует существующее .venv программы. Если оно не найдено,
проверьте выбор папки. Если окружение не запускается — передайте текст сообщения;
не устанавливайте пакеты самостоятельно. Программу останавливать не нужно.

Диагностика читает XLSX, текущие карточки и существующий ключ, но не создаёт
ключ и не записывает данные в SQLite. BIO, XLSX, настройки и приложение не меняет.
В JSON нет значений ключей/подписей, .env, токенов, базы или текстов биографий.
Есть версия, SHA/размер файла, HMAC-счётчики, ID/поля/категории отказов.
Ничего не отправляется автоматически: JSON передаёте вручную.

Для исключения создания DB/WAL/SHM SQLite читается immutable read-only.
Если база в WAL-режиме или есть активный журнал, комплект безопасно остановит
проверку БД и запишет код ограничения в JSON. Не меняйте режим базы самостоятельно.
Поскольку приложение продолжает работать, live-consistency не доказана:
расхождения карточек помечаются как неподтверждённые, а не как доказанный stale.

Не удаляйте TEMP и не меняйте signing.key, .env, скрытые листы или подписи XLSX.
Не пересылайте ключи и всю базу. Новую выгрузку пока делать не требуется.
Этот комплект не импортирует данные и не повторяет исследование биографий.
Если Windows блокирует запуск по политике организации, передайте сообщение
Александру; системные политики и антивирус отключать не нужно.
