# Fedorinov Rewards Web Preview: инструкция

## Что это за архив

Это переносная preview-версия web-приложения Fedorinov Rewards для проверки на Windows.

Это не установщик и не финальная production-версия. Архив содержит только код программы, стартовые файлы и инструкции.

Архив НЕ содержит:

- базу данных;
- фотографии;
- backup-копии;
- личные данные;
- старые `.exe` файлы Windows-приложения.

База и фотографии остаются на вашем компьютере в вашей локальной папке Rewards. Программа работает локально на компьютере и ничего не отправляет в облако.

## Что нужно установить

Перед запуском установите Python 3.11 или новее.

При установке Python обязательно отметьте пункт:

```text
Add Python to PATH
```

После установки Python можно запускать `start_windows.bat`.

## Как распаковать и запустить

1. Распакуйте архив `FedorinovRewards_WebPreview_v0.1.zip` в отдельную папку.
2. Откройте распакованную папку `FedorinovRewards_WebPreview`.
3. Запустите двойным кликом файл:

```text
start_windows.bat
```

При первом запуске программа создаст файл `.env` и откроет его в Notepad.

В файле `.env` нужно указать путь к вашей локальной папке Rewards.

Найдите строку:

```text
REWARDS_DATA_DIR=C:\Path\To\Rewards
```

Замените ее на реальный путь, например:

```text
REWARDS_DATA_DIR=D:\Rewards
```

Сохраните `.env`, закройте Notepad и запустите `start_windows.bat` снова.

## Что должно быть внутри папки Rewards

Папка, указанная в `REWARDS_DATA_DIR`, должна содержать:

```text
database\MyDatabase.sqlite
Source\
SourceMark\
default\
```

Желательно, чтобы также был файл:

```text
default\nofoto.jpg
```

## Как открыть web-интерфейс

После запуска откройте в браузере:

```text
http://127.0.0.1:8080
```

Если `start_windows.bat` открыл браузер сам, просто дождитесь загрузки страницы. Адрес `http://127.0.0.1:8080` автоматически открывает основной legacy-интерфейс с вкладками старой программы.

## Режим просмотра и режим редактирования

По умолчанию включен рабочий preview-режим:

```text
READ_ONLY=false
WRITE_MODE=true
```

В этом режиме доступны кнопки `Добавить`, `Изменить`, `Удалить`. Защита backup-first остаётся включённой:

```text
REQUIRE_BACKUP_BEFORE_WRITE=true
```

Перед реальным редактированием сделайте backup базы и папок. Если при сохранении появляется сообщение `Create a fresh backup before making changes`, значит приложение не нашло свежий backup. Сделайте backup или временно выключите проверку только для тестовой копии данных:

```text
REQUIRE_BACKUP_BEFORE_WRITE=false
```

Чтобы выключить редактирование и оставить только просмотр, откройте `.env` и установите:

```text
READ_ONLY=true
WRITE_MODE=false
```

Сохраните `.env` и перезапустите `start_windows.bat`.

## Как сделать backup перед редактированием

Простой вариант:

1. Закройте программу.
2. Скопируйте папку `database` в безопасное место.
3. Лучше скопируйте всю папку Rewards целиком в безопасное место.
4. Убедитесь, что копия открывается и файлы на месте.
5. Только после этого включайте:

```text
WRITE_MODE=true
```

Не включайте режим редактирования на единственной рабочей копии данных без backup.

## Обновления

В программе есть проверка наличия новой версии через публичный GitHub Release.

Для проверки обновлений GitHub token не нужен. Программа не отправляет в GitHub базу, фотографии, папки `Source`, `SourceMark` или другие пользовательские данные.

Программа показывает, доступна ли новая версия, выводит список изменений простым языком и может установить обновление кнопкой. После установки обновления приложение нужно перезапустить вручную.

Проверить обновления можно во вкладке:

```text
О программе -> Обновления -> Проверить обновления
```

Если доступна новая версия, появится кнопка:

```text
Обновить
```

Как обновиться:

1. Откройте вкладку `О программе`.
2. Нажмите `Проверить обновления`.
3. Если доступна новая версия, прочитайте список изменений.
4. Отметьте подтверждение, что после обновления нужен перезапуск.
5. Нажмите `Обновить`.
6. Дождитесь сообщения:

```text
Обновление установлено. Закройте окно запуска и запустите start_windows.bat снова.
```

7. Закройте окно `start_windows.bat`.
8. Запустите `start_windows.bat` снова.

При обновлении программа сохраняет текущие файлы приложения в backup. База, фотографии, `.env`, папки `database`, `Source`, `SourceMark`, `default` не должны изменяться.

## Если не запускается

### Python не найден

Установите Python 3.11 или новее и отметьте `Add Python to PATH`.

После установки закройте старое окно запуска и снова откройте `start_windows.bat`.

### Не указан REWARDS_DATA_DIR

Откройте `.env` и замените:

```text
REWARDS_DATA_DIR=C:\Path\To\Rewards
```

на реальный путь к папке Rewards.

### База не найдена

Проверьте, что внутри папки из `REWARDS_DATA_DIR` есть файл:

```text
database\MyDatabase.sqlite
```

Если база лежит в другой папке, исправьте `REWARDS_DATA_DIR`.

### Фото не отображаются

Проверьте, что рядом с базой есть папки:

```text
Source\
SourceMark\
default\
```

Если фотография отсутствует, программа должна показать заглушку `Нет фото`.

### Порт 8080 занят

Откройте `.env` и замените:

```text
APP_PORT=8080
```

на:

```text
APP_PORT=18080
```

Сохраните `.env`, перезапустите `start_windows.bat` и откройте:

```text
http://127.0.0.1:18080
```
