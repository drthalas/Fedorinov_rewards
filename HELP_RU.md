# Fedorinov Rewards Web Preview: инструкция

## Что это за архив

Это переносная preview-версия web-приложения Fedorinov Rewards для проверки на Windows.

Это не установщик и не финальная production-версия. Архив содержит только код программы, стартовые файлы и инструкции.

Архив НЕ содержит:

- базу данных;
- фотографии;
- backup-копии;
- личные данные;
- старые `.exe` файлы Windows-приложения.

База и фотографии остаются на вашем компьютере в вашей локальной папке Rewards. Программа работает локально на компьютере и ничего не отправляет в облако.

## Что нужно установить

Перед запуском установите Python 3.11 или новее.

При установке Python обязательно отметьте пункт:

```text
Add Python to PATH
```

После установки Python можно запускать `start_windows.bat`.

## Как распаковать и запустить

1. Распакуйте архив `FedorinovRewards_WebPreview_v0.1.zip` в отдельную папку.
2. Откройте распакованную папку `FedorinovRewards_WebPreview`.
3. Запустите двойным кликом файл:

```text
start_windows.bat
```

При первом запуске программа создаст файл `.env` и откроет его в Notepad.

В файле `.env` нужно указать путь к вашей локальной папке Rewards.

Найдите строку:

```text
REWARDS_DATA_DIR=C:\Path\To\Rewards
```

Замените ее на реальный путь, например:

```text
REWARDS_DATA_DIR=D:\Rewards
```

Сохраните `.env`, закройте Notepad и запустите `start_windows.bat` снова.

## Что должно быть внутри папки Rewards

Папка, указанная в `REWARDS_DATA_DIR`, должна содержать:

```text
database\MyDatabase.sqlite
Source\
SourceMark\
default\
```

Желательно, чтобы также был файл:

```text
default\nofoto.jpg
```

## Как открыть web-интерфейс

После запуска откройте в браузере:

```text
http://127.0.0.1:8080
```

Если `start_windows.bat` открыл браузер сам, просто дождитесь загрузки страницы. Адрес `http://127.0.0.1:8080` автоматически открывает основной legacy-интерфейс с вкладками старой программы.

## Режим просмотра и режим редактирования

По умолчанию включен рабочий режим:

```text
READ_ONLY=false
WRITE_MODE=true
```

В этом режиме доступны кнопки `Добавить`, `Изменить`, `Удалить`. Все изменения сохраняются сразу. Удаления и другие опасные действия остаются защищёнными подтверждением и отдельной проверкой ссылок.

Чтобы выключить редактирование и оставить только просмотр, откройте `.env` и установите:

```text
READ_ONLY=true
WRITE_MODE=false
```

Сохраните `.env` и перезапустите `start_windows.bat`.

## Как сделать backup перед серьёзной работой

Резервную копию стоит регулярно делать перед большим объёмом работ.

Простой вариант:

1. Закройте программу.
2. Скопируйте папку `database` в безопасное место.
3. Лучше скопируйте всю папку Rewards целиком в безопасное место.
4. Убедитесь, что копия открывается и файлы на месте.
5. После этого продолжайте работу в программе.

## Обновления

В программе есть проверка наличия новой версии через публичный GitHub Release.

Для проверки обновлений GitHub token не нужен. Программа не отправляет в GitHub базу, фотографии, папки `Source`, `SourceMark` или другие пользовательские данные.

Программа показывает, доступна ли новая версия, выводит список изменений простым языком и может установить обновление кнопкой. После установки обновления приложение нужно перезапустить вручную.

Проверить обновления можно во вкладке:

```text
О программе -> Обновления -> Проверить обновления
```

Если доступна новая версия, появится кнопка:

```text
Обновить
```

Как обновиться:

1. Откройте программу.
2. Перейдите в раздел «О программе».
3. Нажмите «Проверить обновления».
4. Нажмите «Обновить».
5. Дождитесь завершения установки.
6. Если включён автоматический перезапуск, программа откроется самостоятельно.
7. Если программа не запустилась автоматически, откройте её вручную через `start_windows.bat`.

Данные и фотографии при обновлении сохраняются. Программа также сохраняет текущие файлы приложения в backup; `.env`, папки `database`, `Source`, `SourceMark`, `default` не должны изменяться.

## Рабочий режим редактирования

В рабочей сборке редактирование включено:

```text
READ_ONLY=false
WRITE_MODE=true
```

Обычные изменения можно сохранять без создания резервной копии перед каждым действием:

- добавить или изменить кавалера;
- добавить или изменить награду;
- добавить или изменить знак;
- изменить справочник;
- добавить, заменить или отвязать фото;
- изменить биографию, комментарии, ссылки, номера и цены.

Файл `.env` обычно настраивается один раз. При обновлениях приложения `.env` сохраняется.

Удаления и другие опасные действия остаются защищёнными подтверждением и проверками. Перед серьёзной работой рекомендуется делать резервную копию данных.

## Если не запускается

### Python не найден

Установите Python 3.11 или новее и отметьте `Add Python to PATH`.

После установки закройте старое окно запуска и снова откройте `start_windows.bat`.

### Не указан REWARDS_DATA_DIR

Откройте `.env` и замените:

```text
REWARDS_DATA_DIR=C:\Path\To\Rewards
```

на реальный путь к папке Rewards.

### База не найдена

Проверьте, что внутри папки из `REWARDS_DATA_DIR` есть файл:

```text
database\MyDatabase.sqlite
```

Если база лежит в другой папке, исправьте `REWARDS_DATA_DIR`.

### Фото не отображаются

Проверьте, что рядом с базой есть папки:

```text
Source\
SourceMark\
default\
```

Если фотография отсутствует, программа должна показать заглушку `Нет фото`.

## Работа с фотографиями и каталогом кавалера

При клике на фотографию она открывается крупно прямо поверх текущей страницы. В окне просмотра можно:

- приблизить фото кнопкой `+`;
- отдалить фото кнопкой `-`;
- вернуть исходный масштаб кнопкой `Сброс`;
- двигать увеличенное фото мышкой;
- закрыть окно клавишей `Esc` или крестиком.

В формах редактирования фото можно добавить или заменить кнопкой `+`, отвязать кнопкой `×`, а также попробовать `Вставить из буфера`. Вставка из буфера зависит от браузера: если браузер не разрешает читать изображение из буфера обмена, используйте кнопку `+`.

На главном экране у выбранного кавалера есть действия:

- `Открыть каталог` — открывает локальную папку `Source\<номер кавалера>`;
- `Архивировать` — создаёт архив только этой папки кавалера.

При архивации программа открывает системное окно сохранения файла. Выберите папку и имя архива, затем подтвердите сохранение. После создания программа покажет путь, куда сохранён архив. Если окно выбора закрыть или нажать отмену, архив не создаётся. Исходные фотографии и документы не удаляются.

## Буклет кавалера

На главном экране у выбранного кавалера нажмите:

```text
Сформировать буклет
```

Откроется предпросмотр буклета. В него входят:

- ФИО, звание / специальность и дата рождения;
- краткая биография и комментарий, если они заполнены;
- ссылки `Память народа` и `Форум коллекционеров`;
- фото кавалера и документы;
- список наград с номерами, наличием, датой покупки, ценами и фотографиями.

На странице буклета можно:

- нажать `Печать / сохранить в PDF`;
- нажать `Сохранить PDF`.

При сохранении PDF программа открывает системное окно выбора файла. Выберите место сохранения и подтвердите. После успешного сохранения программа покажет путь к PDF.

Если системное окно сохранения недоступно в текущем окружении, используйте печать страницы и сохранение в PDF средствами браузера.

База и фотографии при формировании буклета не изменяются. Если фото отсутствует или файл не найден, буклет всё равно открывается.

### Порт 8080 занят

Откройте `.env` и замените:

```text
APP_PORT=8080
```

на:

```text
APP_PORT=18080
```

Сохраните `.env`, перезапустите `start_windows.bat` и откройте:

```text
http://127.0.0.1:18080
```
